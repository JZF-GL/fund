# 基金次日涨跌预测（AI 策略）

用户每个交易日 **14:40–14:50** 会主动来触发。你要用「实时估值 + 持仓行情 + 历史净值 + 联网消息面」做一次判断，为两只基金各给一个 **下一交易日收盘方向**（涨 / 跌），把结果写入 `data/ai-predictions.json`，页面「猜次日涨跌日历」会自动读取并和真实净值对账。

**重要：判断完立即调用 `save-prediction.js` 落盘，不要等收盘、不要先问用户确认、不要只给口头结论。** 用户明确要求「预测后直接登记预测记录」。

## 0. 前置检查

```powershell
# 页面服务应已运行在 5173
Invoke-RestMethod http://127.0.0.1:5173/api/status | ConvertTo-Json -Depth 3
```

如果连不上：先 `Start-Process node -ArgumentList server.js -WorkingDirectory E:\code\fund -WindowStyle Hidden`，等 3 秒再继续。

## 1. 拉取本地数据

```powershell
node E:\code\fund\scripts\guess-context.js
```

脚本输出紧凑 JSON，重点字段：

| 字段 | 含义 |
|------|------|
| `targetDate` | 默认的下一工作日（目标预测日） |
| `funds[].lastReal` | 最近一个真实净值交易日与涨跌幅 |
| `funds[].ma5 / ma10 / ma20` | 均线位置 |
| `funds[].aboveMa5 / aboveMa10` | 收盘是否站上均线 |
| `funds[].sum5 / sum10` | 近 5 / 10 日累计涨跌 |
| `funds[].recent` | 最近 10 个交易日明细 |
| `funds[].todayEstimate` | 系统当日实时估值（持仓加权） |
| `funds[].holdingsLive` | 持仓加权贡献、上涨/下跌只数、权重前 8 只 |

若脚本报错，可分别直接读接口：`/api/history`、`/api/daily-estimates`、`/api/holdings/live`。

## 2. 联网检索消息面

用 websearch 查当天与两只基金相关的信息，优先近期（当天或前一晚）：

- AI / 算力 / 半导体：板块新闻、政策、龙头股公告、英伟达等外盘表现
- 新能源车 / 锂电：销量数据、锂价、政策、宁德时代/比亚迪消息
- 大盘环境：上证/创业板当日走势、成交额、北向资金、隔夜美股与 A50 期货
- 次日已知事件：重要数据发布、美联储议息、休市安排

**只采信有来源的内容**，把 URL 或标题记到 `--source`。查不到就说明「无重大消息」，不要编。

## 3. 判断规则（按权重从高到低）

1. **趋势**：站上 MA5 且 MA10、近 5 日累计为正 → 偏涨；反之下跌趋势 → 偏跌
2. **当日强度**：`todayEstimate.pct` 明显放量上涨（>1%）且收盘接近高点 → 次日惯性偏涨；尾盘跳水 → 偏跌
3. **持仓广度**：`holdingsLive.up` 远多于 `down` → 偏涨；权重股集体走弱 → 偏跌
4. **消息面**：明确利好/利空可上调或下调方向；无消息则不加分
5. **大盘环境**：指数普跌时个股难独立走强，反之亦然

输出要求：

- 方向只能是 `up` / `down`（极端不确定可 `flat`，但要说明）
- 置信度 `0-100`：证据一致 60-70；有分歧 50-58；强烈趋势 + 消息共振 70-80。**不要超过 80**
- 至少 2 条、最多 5 条 `--reason`，每条引用具体数据或新闻
- `--summary` 一句话结论（≤40 字）

## 4. 写入预测

对每只基金各执行一次（重复执行会覆盖同一天同基金记录）：

```powershell
node E:\code\fund\scripts\save-prediction.js `
  --fund 012734 `
  --target 2026-11-03 `
  --dir up `
  --conf 62 `
  --summary "算力放量突破，均线多头排列" `
  --reason "收盘站上 MA5/MA10，近5日 +3.2%" `
  --reason "持仓上涨 38 只 / 下跌 6 只，寒武纪 +2.1%" `
  --reason "隔夜纳指涨 1.8%，AI 板块情绪偏暖" `
  --source "https://finance.sina.com.cn/..."
```

- `--target` 用脚本输出的 `targetDate`；若期间有节假日休市，手动顺延到下一交易日
- 目标日必须晚于今天，脚本会校验
- 已存在同目标日记录会被**覆盖**，除非用户明确说「保留旧记录」

## 5. 汇报格式

给用户一个简短表格 + 结论，不要长篇大论：

| 基金 | 猜 | 置信 | 主要依据 |
|------|----|------|----------|
| 012734 AI | 涨 | 62% | 均线多头 + 板块放量 |
| 011513 新能源 | 跌 | 55% | 权重股走弱，锂价回落 |

最后一句：`已写入 data/ai-predictions.json，页面日历可在 <targetDate> 收盘后看到对账结果。`

## 6. 约束

- **不要给投资建议**，只做方向记录与复盘
- 不要伪造数据、新闻或来源
- 同一天不要对同一目标日重复推翻结论（除非用户要求重猜）
- 历史准确率接近 50% 是正常现象，如实说明，不要夸大预测能力
- 页面每 3 分钟刷新一次，写入后用户刷新页面即可看到
